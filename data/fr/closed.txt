# French function words: articles, prepositions (with their contracted
# forms), pronouns, conjunctions, negation. These are answered from this list,
# not by the lexicon service: a listed word loses the lexicon's readings in the
# categories this list owns (Det, Pron, Prep, Conj, Contraction) and every
# lexicon reading whose lemma it lists, so a word lists ALL its categories
# (`pas` the negation and the noun, `tout` determiner, pronoun and adverb).
# One reading per line; a form with several readings has several lines. A
# reading of several morphemes joins them with `+`.
#
# form = lemma:Category{feature=value,...} [+ lemma:Category{...}]
#
# A subject pronoun's adjective agrees with its number (pnum, set by the
# lattice), except vous (polite: vous êtes fatigué) and on (on est partis),
# marked free_pnum=yes.
#
# Features: gender m/f, number sg/pl, person 1/2/3, definite yes/no,
# case nom (subject) / obl (stressed, after a verb or preposition) /
# acc (direct clitic) / dat (indirect clitic) / refl / gen (en) / loc (y),
# clitic yes/no. `next` is the sound the next word starts with: c = a
# consonant or an aspirated h (le héros), v = a vowel or a mute h (l'homme).
# A form allowed before both has no `next`.
