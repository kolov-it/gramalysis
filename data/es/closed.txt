# Spanish function words: articles, prepositions (with their contracted
# forms), pronouns, conjunctions, determiners, question words. These are
# answered from this list, not by the lexicon service. One reading per line;
# a form with several readings has several lines. A reading of several
# morphemes joins them with `+`.
#
# form = lemma:Category{feature=value,...} [+ lemma:Category{...}]
#
# A listed word replaces every lexicon reading of the same lemma, so a word
# with several categories (bajo: preposition, adjective, adverb) lists every
# one of them.
#
# Features: gender m/f, number sg/pl, person 1/2/3, definite yes/no,
# case nom (subject) / obl (stressed, after a preposition) / acc (direct
# clitic) / dat (indirect clitic) / refl / sedat (se standing for le/les
# before lo, la, los, las: se lo doy), clitic yes/no.
#
# Accents keep words apart and are never stripped: tú/tu, él/el, sí/si,
# mí/mi, más/mas, qué/que, cómo/como, dónde/donde, cuándo/cuando,
# quién/quien, cuál/cual. sé and dé are verbs and come from the lexicon.
